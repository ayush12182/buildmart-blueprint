# BuildMart Genesis

Build a premium, modern B2B website for a hardware wholesale company called “BuildMart”.

IMPORTANT:

Use the uploaded BuildMart poster/image as the PRIMARY visual reference for the website’s branding, color palette, typography feel, logo treatment, and overall visual identity.

The brand is:

BUILD MART

HARDWARE WHOLESALE

Tagline:

“SAME ESSENTIALS. A STRONGER TOMORROW.”

Business category:

Hardware Wholesale / Industrial Fasteners / Construction Hardware

Core products:

• Screws

• Nuts

• Bolts

• Washers

• Fasteners

• Industrial hardware

The website should feel like a premium industrial brand — NOT like a cheap local hardware shop and NOT like a generic e-commerce template.

==================================================

DESIGN DIRECTION

==================================================

Create a luxurious, dark, industrial visual identity inspired by the uploaded poster.

Primary colors:

• Deep matte black / near-black background

• Metallic silver / steel

• Electric blue accents

• Premium golden/orange accents

Use blue and gold as subtle accent colors rather than overwhelming the page.

Visual style:

• Premium

• Industrial

• Strong

• Minimal

• Sophisticated

• High-end B2B

• Engineering-focused

• Trustworthy

Use:

• Large typography

• Strong geometric layouts

• Subtle metallic gradients

• Fine blue/gold borders

• Thin technical line patterns

• Abstract engineering/fastener graphics

• Subtle glow effects

• Large product photography

• Soft shadows

• Glass/metal surfaces where appropriate

Avoid:

• Bright white generic backgrounds

• Cartoonish graphics

• Cheap-looking gradients

• Excessive animations

• Generic stock-business imagery

• Overcrowded layouts

• Excessive rounded cards

• Typical Shopify-style appearance

The website should look like a serious national-level industrial hardware brand.
